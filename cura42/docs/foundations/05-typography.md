## Rules

**Do**

- One display-xl per page.
- Lead text up to 60 characters per line, body about 65.
- Tabular figures for numbers in tables.

**Don't**

- Set body copy in the display face.
- Add font sizes or weights outside the scale.
- Set input text below 16 px.
