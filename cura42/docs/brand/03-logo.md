# 03 · Logo

Use the supplied file at its original proportions, every time.

## Clear space

Keep clear space equal to the logo’s height (X) on every side.

## Minimum size

| Height | Use |
| --- | --- |
| 24 px | minimum |
| 32 px | navigation |
| 40 px | print, slides |

## Approved backgrounds

| Background | Hex |
| --- | --- |
| Paper | #FAF6F0 |
| White | #FFFFFF |
| Deep paper | #F4EDE1 |
| Ink, 32 px or larger | #1A1612 |

## Never

- Stretch, squash or change the proportions
- Rotate or tilt the logo
- Recolour it, including to the UI brand colour
- Add shadows, outlines, gradients or glows
- Place it on brand red, accents or busy images
- Separate or rearrange the mark and wordmark
