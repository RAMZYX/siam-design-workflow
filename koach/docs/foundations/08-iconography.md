# 08 · Iconography

One line-icon set on a 24 px grid: 2 px stroke, round caps and joins, currentColor.

_Koach Brand Book v1.0 · generated from index.html_

Files: `assets/icons/<name>.svg` and `assets/icons/sprite.svg` (use as `<svg><use href="sprite.svg#icon-check"/></svg>`).

Every icon is the Icon component, a curated registry over lucide-react addressed by kebab-case name. Never import lucide directly, inline a raw SVG, use emoji as icons or add another icon set. Use 16 px inside buttons, 14–15 px on fact rows, 18–20 px for toolbar and card icons and 26 px inside empty-state chips. Colour icons with a text token, and pair them with text. 25 hand-drawn icons (the hub categories, status markers and similar) live in the codebase as custom SVGs and are not listed here.
