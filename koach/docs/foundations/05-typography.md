## Rules

**Do**

- Use Poppins for headers h1–h6 only, and Inter for everything else.
- Set sub-headers in Inter semibold, never in Poppins.
- Use tabular figures for scores, counts, dates and codes.
- Keep running text near 72 characters; headings use text-wrap: balance.

**Don't**

- Add a font size or weight outside the scale. The off-scale steps (11, 13, 15 px) exist only for dense UI.
- Set body copy in Poppins.
- Use text-tertiary for text people need to read.
