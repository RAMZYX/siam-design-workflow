# Motion Art Direction

Before writing animation code, think like a motion designer.

## Step 1 — Understand the story

Determine:

- What is the user supposed to feel?
- What is the visual message?
- What is the emotional peak?
- What should the user notice first?
- What should they remember?

## Step 2 — Identify the hero

Every animation needs a visual hero.

Examples:

- logo
- typography
- image
- product interface
- character
- shape
- interaction

Do not give every element equal animation importance.

## Step 3 — Build the choreography

Define:

ENTRY
→ BUILD
→ TRANSFORMATION
→ PEAK
→ RESOLUTION

## Step 4 — Define timing

Create a timing map.

Example:

0.0s — setup
0.4s — primary object
0.8s — secondary movement
1.4s — transformation
2.0s — emotional peak
2.5s — resolution

## Step 5 — Define easing

Specify why each movement uses:

- ease-out
- ease-in
- spring
- custom cubic-bezier
- linear

Never choose easing randomly.

## Step 6 — Define transitions

Every transition should have spatial continuity.

Objects should feel like they are transforming into the next scene rather than disappearing and being replaced.

## Step 7 — Prototype

Build the simplest version first.

Then refine:

timing
→ spacing
→ easing
→ choreography
→ micro-details

Do not start with effects.

## Senior art direction rule

If the animation does not work with:

simple shapes
simple typography
simple movement

then adding effects will not fix it.

Fix the choreography first.
