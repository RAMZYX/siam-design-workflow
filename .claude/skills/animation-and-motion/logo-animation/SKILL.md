# Logo Animation Skill

Treat every logo as a visual identity system.

Never animate a logo randomly.

First understand:

- logo geometry
- symbolism
- negative space
- distinctive features
- typography
- brand meaning

## Animation strategy

Find the most distinctive feature of the logo.

Make that feature the emotional hero.

For example:

If a logo contains a heart:
→ the heart becomes the emotional moment.

If a logo contains a leaf:
→ the leaf can drive the transformation.

If a logo contains a letterform:
→ the letter can construct the identity.

## Construction

Prefer:

object appears
→ transforms
→ connects
→ resolves
→ becomes final logo

Instead of:

fade
→ scale
→ bounce
→ finished

## Brand storytelling

Ask:

"What does this logo mean?"

Then make the animation communicate that meaning.

## Letter-based identities

When a brand name is an acronym or a wordmark:

Do NOT simply label each letter with a word.

Instead, let each letterform *behave* like what it stands for, then connect them:

letter one acts out its meaning
→ letter two responds to it
→ a connecting letter links the system
→ the distinctive symbol creates the emotional moment
→ the final letter completes the thought
→ all elements resolve into the complete identity.

Examples of behavior over labels:

- A finance brand: the bars of an "E" rise like a growing chart, then settle into the letter.
- A delivery brand: the dot of an "i" travels in an arc like a parcel and lands in place.
- A wellness brand: an "O" breathes once (slow scale in and out) before locking into the wordmark.

Pick only the behaviors that tell this brand's story. Not every letter needs to perform.

## Final reveal

The final logo should be:

- exact
- recognizable
- stable
- beautifully centered
- given enough time to breathe

Never distort the final logo.

## Timing

Build the animation as a continuous story.

Avoid disconnected scenes.

Every scene should cause the next scene.

## Delivery

- Plan the sequence with motion-art-direction; take lengths and curves from motion-system (logo reveals run 1-3s).
- Deliver as Lottie with lottie-animator (validate before shipping), or as code for web splash screens.
- Provide a reduced-motion version: the final logo with a short fade.
- Run motion-review before calling it done.

## Premium rule

The logo should feel like it was discovered rather than simply displayed.
