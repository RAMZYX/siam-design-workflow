# 08 · Iconography

One line-icon set on a 24 px grid with a 1.8 px stroke and round caps. Click an icon to copy its SVG.

_QCS Brand Book v1.0 · generated from index.html_

Files: `assets/icons/<name>.svg` and `assets/icons/sprite.svg` (use as `<svg><use href="sprite.svg#icon-check"/></svg>`).

QCS uses line icons on a 24 px grid with a 1.8 px stroke and round caps. The admin panel has its own set of about 70 SVG components in <code>src/uiKit/icons</code>; use those first and never redraw them. For anything new, use Lucide (<code>lucide-react</code> is installed), which matches them. This registry lists the Lucide icons QCS code imports today, including the PAL audit area icons, plus the ones QCS screens need. Use 16 px in buttons (8 px gap), 21 px in a 44 px card circle or 42 px chip, and 23 px in the sidebar. Default colour is ink-soft; active is brand. Never use filled icons or text glyphs such as ▦ or ☰.
