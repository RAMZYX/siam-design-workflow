# 12 · Do's and don'ts

Quick rules that keep every screen consistent.

_QCS Brand Book v1.0 · generated from index.html_

| Topic | Do | Don't |
| --- | --- | --- |
| Buttons | Use one primary per page and action teal only for audits and shortcuts. | Show several competing primaries in one area. |
| Colour | Use semantic tokens: teal for action, amber for inactive, red only for failed or spent. | Use raw hex values, legacy colours, or colour alone to show status. |
| Typography | Use Lato and the approved scale; 12 px is the floor. | Add a second typeface or one-off sizes and weights. |
| Radius | Use 8, 12, 20 or pill. | Invent a new radius. |
| Controls | Use 38 px actions, 42 px list search and 48 px form fields and main add button. | Mix control heights in one row. |
| Forms | Show labels, validation and helpful error messages, inside the 520 px modal. | Rely on placeholder text, or use a drawer. |
| Cards & surfaces | White cards, 20 px radius, 20 px padding, shadow-card, hairline dividers. | Darker fills to fake depth, borders on cards, or cards in cards. |
| Shadow | Use shadow-card, shadow-navigation or shadow-overlay; keep table rows flat. | Invent a heavier shadow. |
| Spacing & layout | Use the base-4 scale; work from 1180 px up; stack below 1180 px. | Add one-off gaps or let the page scroll sideways. |
| Icons | Use line icons at 1.8 px with a label; 16, 21 or 23 px. | Use filled icons, text glyphs or mixed colours in one component. |
| Status | Use a dot or pill plus a word; archived is amber; unread is “—”. | Use a bare dot, red for archived, or 0 for an unread value. |
| Tables & data | Keep headers, status and row actions in the same place. | Add shadows to rows or hide status. |
| Navigation | Keep the flat teal sidebar with a square active block. | Use a rounded pill for the active item. |
| Overlays | Use the modal or the tooltip. | Use a drawer or side panel. |
| Feedback | Confirm results and say how to recover from errors. | Show success in teal, or an error with no way forward. |
| Content | Use product words from the word list in British English. | Use code words such as bot or patient. |
| Something missing? | Add it to the design system first, then use it. | Design a one-off for a single screen. |
